# 🚀 Push to GitHub - Quick Commands

## Copy and paste these commands:

```bash
# Navigate to project directory
cd /home/newuser/Music/fs/mcq

# Add GitHub remote (REPLACE YOUR_USERNAME with your actual GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/isl-exam-portal.git

# Push to GitHub
git push -u origin main
```

## Example with actual username:

If your GitHub username is `john123`:

```bash
git remote add origin https://github.com/john123/isl-exam-portal.git
git push -u origin main
```

## After Pushing:

1. ✅ Go to https://vercel.com
2. ✅ Click "Import Project"
3. ✅ Select your GitHub repository
4. ✅ Add environment variable: `NEON_DATABASE_URL`
5. ✅ Click "Deploy"

## That's it! 🎉
